LLM 兜底匹配配置（音效智能重定向）

Freesound 在线检索配置

当本地音效库完全找不到匹配时，系统可自动调用 Freesound API 在线搜索并下载音效。 申请地址：https://freesound.org/apiv2/apply
默认 Token：已内置一个公共 Token，建议申请自己的以提升配额。

提示：留空则下载到 %USERPROFILE%/unitale_sfx，填自定义路径则下载到指定目录。

音色保存目录

提示：留空则落盘到项目目录下的 timbres/；填自定义路径则落盘到指定目录。修改后点"保存目录设置"持久化。

TTS 后端（IndexTTS）按 audio_path 哈希从自己的 PROMPTS_DIR 取音色文件，所以本地音色必须先上传过去才能合成。点下方按钮把当前所有音色一次性同步到当前选中的 TTS 服务，避免合成时报"音频不存在"。
